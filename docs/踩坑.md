# 踩坑清单（本机实测）

按主题分组，每条都是踩过、验证过、有结论的。带 `⚠` 的是会让人查错方向的假象。

## asar（`桌宠\resources\app.asar`）

- 头 16 字节：`[0..3]=4`、`[4..7]=headerSize`、`[8..11]=headerSize-4`、`[12..15]=jsonLen`；JSON 从偏移 16 开始。
- `dataStart = 8 + headerSize`（本包 headerSize 让 dataStart 后还有固定 **10 字节 padding**）；header 里每个文件的 `offset` **相对 dataStart**，不是相对文件头。
- header 里每个条目带 `integrity:{algorithm:"SHA256",hash,blockSize:4194304,blocks:[…]}`；改完必须**等长重算**并回写整体 `sha256` 与每个 block 的 `sha256`（hex 固定 64 字符，jsonLen 不变）。`EnableEmbeddedAsarIntegrityValidation` fuse 开着，不重算 = 启动即崩。
- 等长替换：新代码不足的位置用空格补在语句之间（不能改 header 长度，否则后面所有文件 offset 全错）。
- 备份 4 份各 520MB，实测只有 `app.asar.original-*`（原版）与最近一份 `bak-*`（当前版前一版）有用，中间快照可删。

## motion3（Live2D 动作）

- `Segments` 布局：`[t0, v0, <type 段…>]`，`type=0` 跟 2 个数（t,v），`type=1`（bezier）跟 6 个数。段数必须逐段 `i += 3 / 7` 算，**不能** `(len-2)/3`。
- ⚠ `Segments` 里出现 `null` → Live2D **整只冻住**（连待机呼吸都不动），但控制台照样打印 `Motion started successfully`。成因：`Float32Array.map()` 的返回值被强转成数字 → `NaN` → `JSON.stringify` 写 `null`。修法：`Array.from(arr, fn)`。
- `Curves[].Target` 全是字面量 `"Parameter"`，真正的参数名在 `Id`。
- 头部参数是 `AngleX/AngleY/AngleZ` + `LeanInput`，**不是** `ParamAngleX/Y/Z`。
- `Movement1/2/3` 是**换手组开关**（中文名「1.狗尾草 / 2.抚胸 / 3.竖食指」）。原版 Talk 动作里这三点全 0，只当标记用。加权平均两个组 = 两套手臂绑骨同时半开 = **残影**；必须逐帧二值化（取绝对值最大者置 1）。
- 物理输出参数不可写：`LArm/RArm/LForearm/RForearm/LHand/RHand/ShoulderY/ShoulderZ`；可写 `Param36/39/40/41/43/59/60/61/62` + `ShoulderX`。
- 手举起不会自己落下：`待机.motion3.json` 已删 13 条手部曲线（`Movement1/2/3` + `Param36/39/40/41/42/43/59/60/61/62`），Cubism 每帧只更新「本帧有曲线的参数」。必须显式播收回动作。
- 表情叠加通道（`LCry/RCry/SweatBurst1-4/ShockL/ShockR/CheeckPuff/key1..13/Paramshuiyin7/Startwinkle/Divider22/Clothes1/Clothes2`）跨段混会闪眼泪汗滴 → 编排时一律不输出。
- 同一套右臂 rig 的手指类与道具类动作**末帧姿态几乎相同**（`表演-06-手指`/`表演-08-狗尾草` 末帧都是 `Param56=0.58`、`Param57=0.40`），贴在一起就是「手指一放凭空出草」→ 中间必须插 base 过渡。

## OPFS / airi

- 权威模型在 `%APPDATA%\ai.moeru.airi\File System\000\t\01\`（`preset-live2d-1\Animation\*`），不是 `resources\app.asar` 里那份。
- 推完必须 `Page.reload {ignoreCache:true}`；`window.__dafeiMotions` 只在模型加载时算一次快照。
- 手工起 airi 必须先清 `ELECTRON_RUN_AS_NODE`（DSH 会话环境里它是 1，airi 会当 Node 跑然后秒退，`ExitCode=0` 无报错）；顺带清 `NODE_OPTIONS/NODE_PATH/NODE_ENV/ELECTRON_*`。
- `setMotion`/`dafeiPlayFile` 都不是全局；页面里有 `BroadcastChannel('dafei-motion-preview')`（`globalThis.__dafeiPreviewChannel`）收 `{group,index}` / `{toggle:'跳舞'}`，但**同页自己 post 收不到，必须从 Worker 投**。
- 长动作会被顶成 Think：`pages-*.js` 的 `holdsVoice(context)`（`:812`）→ `onBeforeSend` 里 `setMotion(EmotionThinkMotionName, FORCE)`（`:822-825`），源头是 `/dafei/pending` 轮询 → 录制/演长动作前 `POST /dafei/pause {on:true}`。
- 绿幕不可行：窗口是 `LAYERED + TRANSPARENT`，Electron 忽略背景 override → 只能 PNG+alpha（或 OBS 窗口采集透明背景）。

## 环境

- 系统 `python`（Python312）坏：`Fatal Python error: init_fs_encoding … No module named 'encodings'`（`PYTHONHOME` 被指到 `D:\ComfyUI`）→ 一律 `D:\AI\RVCover\py311\python.exe`；`py` 启动器被 niubash 拦。
- 控制台是 GBK，中文输出乱码 → 脚本写 UTF-8 文件再读；Python 侧设 `PYTHONIOENCODING=utf-8 PYTHONUTF8=1`。
- Node 里 `/d/...` 会解析成 `D:\d\...`；Python 不认 MSYS 路径。
- `RVCover\bin` 没有 `ffplay` → 播放用 `System.Media.SoundPlayer`。
- `ops_bash` 跑完会连子进程一起杀 → 验证长任务（TTS/RVC/录制）只能靠插件长活进程或写日志看结果。
- `modlens_read_image` 常撞 `finish_reason=length`；纯文本模型没有视觉 → 判断画面用像素差（`ffmpeg -f rawvideo -pix_fmt gray` + numpy 逐帧差），别指望"读一眼"。
- PowerShell 函数返回值要强制类型（`[int]` / `[string]`），否则管道里会带出多余对象。
- `.ps1` 文件一律 UTF-8 **with BOM**（PS 5.1 按 GBK 读，中文会吃引号并报无关语法错）。
