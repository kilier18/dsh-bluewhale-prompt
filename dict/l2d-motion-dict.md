# Live2D 动作语义字典（官方 44 条）

> 由 `scripts/l2d-dict.py` 从 OPFS 现网动作库机械拆解生成，**所有数字都是原作者曲线里的实测值，不是估算**。
> 重新生成：`node scripts/pull-motions.mjs --out .motions-lib` 再 `python scripts/l2d-dict.py --lib .motions-lib --out dict/l2d-motion-dict.json --mapping dict/l2d-motion-mapping.json --md dict/l2d-motion-dict.md`。

## 1. 怎么用这本字典

1. 先定**情绪档**（steady / cozy / bomb），再从该档里挑 1 条动作当"身体层"；
2. 手臂层**不要自己拧关节**，只从 `正常说话-抚胸 / 正常说话-食指 / 正常说话-狗尾草` 三条原片里取，用 `l2d-compose.mjs` 的 `armMap` 做时间重映射；
3. 一条编排里换手 ≤2 次、每次保持 ≥8s；
4. 表情只用叠加型（`脸红/爱心眼`），任何 `key*` 换脸表情会吃掉嘴部动画，唱歌场景禁用。

## 2. 参数族

| 族 | 参数 | 是否可写 | 备注 |
|---|---|---|---|
| 头 | AngleX/Y/Z | ✅ | 头转向/点头/歪头，单位度 |
| 身 | PositionX/Y/Z、LeanInput、ShoulderX | ✅ | **唯一能撑大幅度的族** |
| 胸腔 | ParamBodyAngleX/Y/Z/RX/RY/RZ、ChestX1/Y1、Param138 | ❌ 无效 | 实测写入后画面零变化，别用 |
| 眼 | ParamEyeLOpen/ROpen、ParamEyeBallX/Y、EyeSmile | ✅ | |
| 口 | ParamMouthOpenY/Form、MouthSmile_L/R | ✅ | 唱歌时 MouthOpenY 归音频口型 |
| 臂 | Movement1/2/3 + Param11/27–32/36–43/55–62 | ⚠️ | 只能整体搬作者片段的窗口 |
| 物理输出 | LArm/RArm/LForearm/RForearm/LHand/RHand/ShoulderY/Z/Param55/Param58 | ❌ | 引擎每帧覆写 |

## 3. 幅度三档（按实测极值划分）

| 档 | 判据 | 用法 |
|---|---|---|
| steady | PositionX ≤10 且 LeanInput ≤12 | 讲话、主歌铺底 |
| cozy | PositionX ≤19 或 LeanInput ≤−20 | 主歌、撒娇、副歌前 |
| bomb | PositionX ≥20 | 只做副歌爆点，别连用 |

## 7. 硬规则（违反就会翻车，都是踩过的）

1. `AngleZ` 只能有一个来源：`tilt` 与 `pose`/`sway` 混写会直接编译报错；
2. `PositionZ` 同理：`tilt` 自己就会写 PositionZ，别和 `pose` 里的 PositionZ 叠；
3. `tilt`/`nod`/`look`/`sway` 已经各自占好参数，见 §2 归属表，别越界；
4. 手臂曲线**整条搬**（含 Param11/27–32 手掌手指串），只搬 20 个大参数会丢手指姿态 → 抬手落手出现"多一条手臂"；
5. `Movement1/2/3` 是换手组开关，作者原件是 0.8s 斜坡，**禁止二值化**（二值化 = 两套绑骨半开 = 残影）；
6. 烘焙 `FadeInTime/FadeOutTime` 必须是 0（曲线自己带缓动，再叠引擎 fade 就是三重软化 = 起手慢）；
7. 微笑要打成 0.4s 的**脉冲**（官方是 0.8s/14.3s/27.9s 三次），不要整段挂着；
8. 头比身体**晚 0.1–0.3s** 跟随，同时动会显得假；
9. 单条编排 ≤64 个 action，单段 0.2–20s（expression 到 59s），总长 ≤60s；
10. 收尾必须回中立：最后 0.9s 内所有参数归默认，否则切回待机会"甩"。
