# 动作语义字典 · agent 速查卡

> 这份文件由 `node scripts/gen-prompt.mjs` 从 `dict/l2d-motion-dict.json` 生成，别手改。
> 数据来源：桌宠 OPFS 里 44 条官方 motion3 的逐帧实测（作者原曲线，不是估算）。

## 怎么用（三步）

1. **定档**：先确定这句话的情绪落在 `steady` / `cozy` / `bomb` 哪一档，再从该档挑一条动作当「身体层」。
2. **挑窗口**：别用片段开头，用 `bestWindow(name, 时长)` 给的活跃窗口（字典里 `bestWindows` 已经预算好 4/6/10/14/20s）。
3. **配手臂**：手臂只从 `正常说话-抚胸 / 正常说话-食指 / 正常说话-狗尾草` 三条原片整条搬，按 `armMap` 做时间重映射；一条编排换手 ≤2 次。

在线查询（插件起着的时候）：

```
GET /dafei/dict                                    # 全量索引
GET /dafei/dict?intent=撒娇&duration=12             # 直接给建议：动作、起始秒、手臂映射
GET /dafei/dict?text=1&limit=20                     # 纯文本速查（可直接塞进 prompt）
```

## 幅度三档

- **steady** —— 稳态：PositionX/AngleZ ≤10，适合讲话、副歌前的铺底
- **cozy** —— 黏人档：PositionX ≤19 或 LeanInput ≤−20，适合主歌、撒娇
- **bomb** —— 炸场档：PositionX ≥20，只适合副歌爆点，别连续用

## 铁律
1. 身体层只用 PositionX/Y/Z、LeanInput、ShoulderX；ParamBodyAngle*、Chest*、Param138 在本模型上无效，禁用。
2. 没有「胸腔扭腰」这回事：官方所谓的扭 = PositionX ±14 + PositionZ ±13（表演-05-重心）。
3. 手臂只从 正常说话-抚胸 / 正常说话-食指 / 正常说话-狗尾草 三条原片整条搬（含 Param11/27–32 手指串），禁止自己拧关节。
4. 一条编排换手 ≤2 次、每次保持 ≥8s；Movement1/2/3 是换手开关，作者是 0.8s 斜坡，禁止二值化。
5. AngleZ 只允许一个来源：tilt 会同时写 AngleZ + PositionZ，不能再和写这两个参数的 pose / sway 共存。
6. 烘焙 FadeInTime / FadeOutTime 必须是 0；收尾 0.9s 内回中立。
7. 表情只用叠加型：脸红 key7、爱心眼 key4、兔牙 key9；key1/3/5/6/10 是整脸换层，会顶掉嘴部动画。
